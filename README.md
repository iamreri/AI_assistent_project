# AI-ассистент для студентов МГТУ им. Г.И. Носова

RAG-ассистент, который отвечает на вопросы студентов по учебному процессу, сессии, практике, ВКР, стипендиям и общежитию на основе официальных документов университета и возвращает источники вместе с ответом.

## Статус
- [x] Задание 1: проектирование
- [x] Задание 2: база знаний (собраны 10 актуальных студенческих документов, проведено сравнение чанкинга)
- [x] Задание 3: RAG-компонент (реализован пайплайн, проведены 3 эксперимента)

## Целевая аудитория
Студенты МГТУ им. Г.И. Носова (бакалавриат, специалитет, магистратура).

## Стек технологий (RAG-пайплайн)
- **Vector DB:** ChromaDB
- **Embeddings:** `intfloat/multilingual-e5-small`
- **LLM (Генерация):** GigaChat API (от Сбера)
- **Язык:** Python 3.11

## Инструменты разработки (dev-AI)
При разработке системы использовались:
- **ChatGPT** — генерация и рефакторинг кода, документация;
- **DeepSeek** — подготовка тестовых вопросов, ревью промптов, отладка.

> Важно: это инструменты, помогавшие писать код, а не модель, работающая внутри RAG-пайплайна. Модель внутри пайплайна — GigaChat.

## Структура репозитория
- `data/` — база знаний: `sources.csv`, `documents/` (очищенные тексты), `chunks/` (чанки);
- `docs/` — проектная документация (включая `rag.md` с описанием архитектуры и экспериментов);
- `scripts/` — скрипты подготовки данных и запуска экспериментов;
- `src/` — исходный код RAG-ассистента (разбит на `embeddings`, `retrieval`, `generation`, `rag`);
- `experiments/` — отчеты по трем проведенным экспериментам (chunk size, top_k, embedding models).

## Как запустить (кратко)
1. Установить зависимости: `pip install -r requirements.txt` *(если создадите его)* или `pip install chromadb sentence-transformers openai python-dotenv httpx requests`.
2. Добавить ключ GigaChat в файл `.env`.
3. Запустить тестовый скрипт: `python -m scripts.run_experiment_top_k` (или `python test_rag.py`).
