# AI-ассистент для студентов МГТУ им. Г.И. Носова

RAG-ассистент, который отвечает на вопросы студентов по учебному процессу, сессии, практике, стипендиям и общежитию на основе официальных документов университета и возвращает источники вместе с ответом.

## Статус проекта
- [x] Задание 1: проектирование (см. `docs/`)
- [x] Задание 2: база знаний (собраны 10 ЛНА, проведен чанкинг и оценка)
- [x] Задание 3: RAG-компонент (реализован пайплайн, проведены 3 эксперимента)
- [x] Задание 4: Benchmark (сформировано 100 тестовых сценариев, проведена оценка)

## Целевая аудитория
Студенты МГТУ им. Г.И. Носова (бакалавриат, специалитет, магистратура).

## Стек технологий
- **Язык:** Python 3.11
- **Vector DB:** ChromaDB
- **Embeddings:** `intfloat/multilingual-e5-small`
- **LLM (Генерация):** GigaChat API (Сбер)
- **Оценка качества:** Собственный benchmark из 100 вопросов (6 категорий)

## Инструменты разработки (dev-AI)
При разработке системы использовались:
- **ChatGPT** — генерация и рефакторинг кода, генерация вопросов для бенчмарка;
- **DeepSeek** — ревью промптов, отладка.
*(Подробный журнал запросов находится в файле `AI_USAGE.md`)*.

## Структура репозитория
- `data/` — база знаний (`sources.csv`, очищенные тексты `documents/`, чанки `chunks/`);
- `docs/` — проектная документация (`rag.md` — архитектура RAG, `benchmark.md` — описание тестов);
- `src/` — исходный код ассистента (модули `embeddings/`, `retrieval/`, `generation/`, `rag/`);
- `scripts/` — скрипты подготовки данных и запуска экспериментов;
- `experiments/` — отчеты по 3-м экспериментам (chunk size, top_k, модели);
- `benchmark.csv` — 100 тестовых сценариев;
- `benchmark_results.csv` — ответы ИИ на тесты;
- `chat.py` — интерактивный чат для общения с ассистентом.
