# AI-ассистент для студентов МГТУ им. Г.И. Носова

RAG-ассистент, который отвечает на вопросы студентов по учебному процессу,
сессии, практике, ВКР, стипендиям и общежитию на основе официальных
документов университета и возвращает источники вместе с ответом.

## Статус
- [x] Задание 1: проектирование
- [ ] Задание 2: база знаний (корпус пересобирается под студентов)
- [ ] Задание 3: RAG-компонент

## Целевая аудитория
Студенты МГТУ им. Г.И. Носова (бакалавриат, специалитет, магистратура).

## Инструменты разработки (dev-AI)
При разработке системы использовались:
- **ChatGPT** — генерация и рефакторинг кода, документация;
- **DeepSeek** — подготовка тестовых вопросов, ревью промптов, отладка.

> Это инструменты, помогавшие писать код. Модель внутри RAG-пайплайна
> будет указана в `docs/rag.md` (задание 3).

## Структура репозитория
- `data/` — база знаний: `sources.csv`, `documents/`, `chunks/`
- `docs/` — проектная документация
- `scripts/` — скрипты подготовки данных
