# Целевая аудитория

Основная целевая аудитория — студенты МГТУ им. Г. И. Носова. В рамках прототипа приоритетным пользователем является студент, которому необходимо быстро найти информацию в университетских документах и учебно-методических материалах, а также получить понятное объяснение найденной информации.

# Границы компетенции ассистента

## В рамках компетенции

Ассистент:

- ищет информацию в подготовленной базе университетских документов;
- отвечает на вопросы по содержанию документов, включенных в базу знаний;
- ищет учебно-методические материалы по дисциплине или теме;
- отвечает на вопросы на основе найденных фрагментов документов;
- при необходимости объединяет информацию из нескольких релевантных фрагментов;
- предоставляет пользователю информацию об использованных источниках;
- сообщает об отсутствии информации, если релевантные сведения не найдены в базе знаний;
- запрашивает уточнение, если запрос пользователя недостаточно конкретен для поиска информации.

## Вне компетенции

Ассистент не отвечает на вопросы, выходящие за рамки его компетенции:

- требующие доступа к личному кабинету студента;
- связанные с индивидуальными оценками студента;
- связанные с индивидуальной академической задолженностью;
- требующие получения персональных данных студента из информационных систем университета;
- требующие выполнения административных действий от имени студента;
- если необходимая информация отсутствует в базе знаний;
- если найденной информации недостаточно для формирования достоверного ответа;
- если доступные источники содержат противоречивые сведения, а система не может определить приоритет актуального источника.

# База знаний прототипа

Для реализации прототипа команда формирует ограниченный набор документов, доступных в открытом доступе на официальных ресурсах МГТУ им. Г. И. Носова.

В базу знаний включаются:

- официальные документы университета, находящиеся в открытом доступе;
- положения и регламенты, касающиеся образовательного процесса;
- учебно-методические материалы;
- учебные планы и иные документы, содержащие общую информацию об образовательном процессе;
- справочная информация о структурных подразделениях университета, представленная в выбранных источниках.

Перечень конкретных документов определяется на этапе подготовки прототипа базы знаний.

Персональные данные студентов, индивидуальные оценки, сведения об академических задолженностях и иная информация из личных кабинетов в базу знаний прототипа не включаются.

# Примеры вопросов

## Вопросы, на которые ассистент отвечает

- Какие требования к оформлению курсовой работы установлены университетом?
- Какие документы необходимы для прохождения определенной учебной процедуры?
- Где найти методические указания по конкретной дисциплине?
- Какие требования к оформлению работы указаны в найденных методических рекомендациях?
- Какая информация содержится в определенном положении или регламенте университета?
- Какую информацию предоставляет определенное структурное подразделение университета?
- Что говорится в найденных документах по указанному пользователем вопросу?

## Вопросы, на которые ассистент не отвечает

- Какие у меня оценки за текущий семестр?
- Есть ли у меня академическая задолженность?
- Какие у меня индивидуальные дедлайны?
- Какое расписание назначено лично мне, если соответствующая информация отсутствует в базе знаний?
- Может ли ассистент изменить данные в информационной системе университета?
- Какие персональные данные другого студента хранятся в университете?
- Какая информация доступна по вопросу, если соответствующие документы отсутствуют в базе знаний?

# Использование ИИ

ИИ используется в системе для понимания запросов пользователя на естественном языке и формирования ответа на основе информации, найденной в базе знаний.

Основные функции ИИ:

- понимание смысла запроса пользователя, сформулированного в свободной форме;
- определение намерения пользователя;
- обработка различных формулировок одного и того же вопроса;
- поиск и использование релевантного контекста, полученного из базы знаний;
- анализ найденных фрагментов документов;
- формирование связного и понятного ответа на естественном языке;
- объединение информации из нескольких найденных фрагментов;
- формирование ответа с указанием использованных источников;
- определение случаев, когда найденной информации недостаточно для формирования достоверного ответа.

При этом ИИ не является самостоятельным источником официальной информации. Фактические сведения должны подтверждаться информацией из подготовленной базы знаний и разрешенных источников. Поиск информации и хранение базы знаний являются отдельными компонентами системы. Искусственный интеллект используется для понимания пользовательского запроса, обработки найденного контекста и формирования итогового ответа на его основе.

# Формирование базы знаний

База знаний ассистента формируется на основе документов, размещенных в открытом доступе на официальных информационных ресурсах МГТУ им. Г. И. Носова.

В рамках прототипа используется ограниченный набор документов, относящихся к образовательному процессу в университете:

- нормативные и организационные документы, регламентирующие образовательную деятельность;
- документы по организации практической подготовки и государственной итоговой аттестации;
- документы, регламентирующие использование электронной информационно-образовательной среды и образовательного портала;
- учебные планы и календарные учебные графики отдельных образовательных программ;
- рабочие программы дисциплин;
- учебно-методические материалы по отдельным дисциплинам.

В качестве конкретных источников для прототипа планируется использовать:

- Правила приёма на обучение по образовательным программам высшего образования;
- документ, регламентирующий организацию и осуществление образовательной деятельности по программам высшего образования;
- Положение об электронной информационно-образовательной среде МГТУ им. Г.И. Носова;
- Положение об образовательном портале университета;
- Положение об электронном портфолио обучающегося;
- документ, регламентирующий использование системы «Антиплагиат.ВУЗ»;
- порядок организации практической подготовки при реализации практик по образовательным программам высшего образования;
- документ, регламентирующий проведение государственной итоговой аттестации;
- учебный план одной из образовательных программ;
- рабочие программы нескольких дисциплин выбранной образовательной программы;
- календарный учебный график выбранной образовательной программы;
- учебно-методические материалы по отдельным дисциплинам.

Конкретный перечень файлов, включаемых в базу знаний, фиксируется на этапе подготовки прототипа с указанием наименования документа, источника, даты актуальности и ссылки на исходный материал.

База знаний не содержит персональные данные студентов, сведения об оценках и задолженностях, данные личных кабинетов, индивидуальные расписания и иную информацию, доступ к которой требует авторизации или получения данных из внутренних информационных систем университета.

# Зачем здесь нужен ИИ?

Обычный поиск по сайту позволяет найти документы и отдельные страницы по ключевым словам, однако пользователю необходимо самостоятельно определить, в каком документе содержится нужная информация, найти соответствующий фрагмент и интерпретировать его.

В разрабатываемом ассистенте поиск используется для получения релевантных фрагментов из базы знаний, а ИИ применяется для понимания естественно сформулированного запроса пользователя, обработки найденного контекста и формирования связного ответа. Таким образом, ИИ не заменяет механизм поиска и базу знаний, а используется как дополнительный уровень взаимодействия с информацией.

Например, вместо поиска нескольких документов по запросу «что нужно для оформления академического отпуска?» пользователь задает вопрос в свободной форме. Система находит соответствующие фрагменты документов, передает их в языковую модель и формирует ответ на основе найденной информации с указанием источников. При отсутствии релевантной информации в базе знаний ассистент не должен самостоятельно формировать фактический ответ на основе знаний языковой модели.
