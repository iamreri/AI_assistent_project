# Пользовательские сценарии

## Общая логика работы

Пользователь взаимодействует с ИИ-ассистентом на естественном языке.

Ассистент выполняет поиск информации в заранее подготовленной базе знаний, содержащей выбранные документы МГТУ им. Г.И. Носова и учебно-методические материалы.

Общая последовательность работы:

> Запрос пользователя → поиск релевантных фрагментов → передача найденного контекста языковой модели → формирование ответа → отображение источника.

---

## UC-01. Поиск информации в документах университета

**Цель**
Получить конкретную информацию, содержащуюся в документах МГТУ им. Г.И. Носова.

**Предусловие**
Необходимый документ или информация содержится в подготовленной базе знаний.

**Основной сценарий**
1. Студент задаёт вопрос на естественном языке.
2. Система анализирует содержание запроса.
3. Система выполняет поиск релевантных фрагментов документов в базе знаний.
4. Система передаёт найденные фрагменты языковой модели.
5. Языковая модель формирует ответ на основе найденной информации.
6. Система отображает ответ и источник информации.

**Пример**
Запрос пользователя:
> «Какие требования предъявляются к курсовой работе?»

Результат:
Ассистент формирует ответ на основании соответствующего методического документа и указывает использованный источник.

**Альтернативный сценарий**
Если релевантная информация не найдена, система сообщает пользователю, что необходимая информация отсутствует в подготовленной базе знаний.

## UC-02. Поиск учебно-методических материалов

**Цель**
Найти учебно-методический материал по заданной дисциплине или теме.

**Предусловие**
Соответствующие учебно-методические материалы включены в базу знаний.

**Основной сценарий**
1. Студент указывает дисциплину, тему или интересующий его материал.
2. Система анализирует запрос.
3. Система выполняет семантический поиск по базе знаний.
4. Система находит релевантные документы или их фрагменты.
5. Система предоставляет информацию о найденных материалах.
6. Система указывает источники.

**Пример**
Запрос пользователя:
> «Найди методические материалы по выполнению лабораторных работ по дисциплине X».

Результат:
Ассистент находит соответствующие материалы в базе знаний и сообщает пользователю, в каких документах содержится необходимая информация.

---

## UC-03. Получение информации об учебных процедурах

**Цель**
Получить информацию о порядке выполнения учебной процедуры на основании официальных документов университета.

**Предусловие**
Документ, регламентирующий соответствующую процедуру, содержится в базе знаний.

**Основной сценарий**
1. Студент задаёт вопрос о порядке выполнения учебной процедуры.
2. Система выполняет поиск соответствующих документов.
3. Система извлекает релевантные фрагменты.
4. Языковая модель формирует ответ на основе найденного контекста.
5. Система указывает источник информации.

**Пример**
Запрос пользователя:
> «Какие документы необходимы для прохождения этой процедуры?»

или:

> «Каков порядок прохождения данной учебной процедуры?»

**Ограничение**
Сценарий не предусматривает получение персональной информации о студенте, его оценках, задолженностях, индивидуальных сроках или состоянии заявлений.

## UC-04. Поиск информации по расписанию в базе знаний

**Цель**
Найти информацию о расписании, если соответствующий документ включён в базу знаний.

**Предусловие**
Документ с расписанием должен быть заранее добавлен в базу знаний.

**Основной сценарий**
1. Студент задаёт вопрос о расписании.
2. Система выполняет поиск информации в базе знаний.
3. Система находит соответствующий фрагмент документа.
4. Система формирует ответ на основании найденной информации.
5. Система указывает документ-источник.

**Пример**
Запрос пользователя:
> «Когда проходит занятие по дисциплине X согласно опубликованному расписанию?»

**Ограничение**
Система не получает расписание напрямую из информационных систем университета и не гарантирует актуальность расписания, если соответствующий документ отсутствует или не был обновлён в базе знаний.

## UC-05. Получение объяснения учебного материала

**Цель**
Получить понятное объяснение информации, содержащейся в учебно-методических материалах.

**Предусловие**
Информация по теме содержится в документах базы знаний.

**Основной сценарий**
1. Студент задаёт вопрос по учебному материалу.
2. Система выполняет семантический поиск релевантных фрагментов.
3. Система передаёт найденный контекст языковой модели.
4. Языковая модель формирует объяснение на основе найденного материала.
5. Система отображает объяснение и источник.

**Пример**
Запрос пользователя:
> «Объясни простыми словами принцип работы метода, описанного в методичке».

Результат
Ассистент не просто показывает документ, а использует языковую модель для преобразования найденной информации в связное и понятное объяснение.

---

## UC-06. Получение ответа на вопрос по содержанию документа

**Цель**
Получить ответ на конкретный вопрос по информации, содержащейся в документах базы знаний.

**Предусловие**
Ответ на вопрос содержится в одном или нескольких документах базы знаний.

**Основной сценарий**
1. Студент формулирует вопрос.
2. Система выполняет семантический поиск.
3. Система определяет релевантные фрагменты одного или нескольких документов.
4. Языковая модель анализирует найденный контекст.
5. Система формирует связный ответ.
6. Система указывает использованные документы.

**Пример**
Запрос пользователя:
> «Какие требования указаны в положении к выполнению данной работы?»

**Особенность**
Если для ответа требуется информация из нескольких документов, система может использовать несколько найденных фрагментов при условии, что они относятся к запросу пользователя.

---

## UC-07. Обработка запроса при отсутствии информации

**Цель**
Предотвратить формирование неподтверждённого ответа, если необходимая информация отсутствует в базе знаний.

**Предусловие**
Пользователь задаёт вопрос, для которого в базе знаний отсутствуют релевантные материалы.

**Основной сценарий**
1. Студент задаёт вопрос.
2. Система выполняет поиск по базе знаний.
3. Система не находит достаточного количества релевантной информации.
4. Система сообщает пользователю, что необходимая информация отсутствует в подготовленной базе знаний.
5. Система не формирует фактический ответ на основе собственных знаний языковой модели.

**Пример**
Запрос пользователя:
> «Какая у меня академическая задолженность?»

Результат
Система сообщает, что не располагает персональной информацией студента и не может предоставить такие сведения.
